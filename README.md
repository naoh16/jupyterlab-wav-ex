# jupyterlab_wav_ex

[![Github Actions Status](https://github.com/naoh16/jupyterlab-wav-ex/workflows/Build/badge.svg)](https://github.com/naoh16/jupyterlab-wav-ex/actions/workflows/build.yml)
[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/naoh16/jupyterlab-wav-ex/main?urlpath=lab)

A JupyterLab MIME rederer Extension for RIFF-wav files

This extension is inspired from
[jupyterlab-wav](https://github.com/wrist/jupyterlab-wav) by @wrist
and
its [forked-version](https://github.com/naoh16/jupyterlab-wav) by @naoh16.

![](https://raw.githubusercontent.com/naoh16/jupyterlab-wav-ex/master/docs/img/jupyterlab_wav_ex_ss1.png)

## Requirements

- JupyterLab >= 4.0.0

## Install

To install the extension, execute:

```bash
pip install jupyterlab_wav_ex
```

## Uninstall

To remove the extension, execute:

```bash
pip uninstall jupyterlab_wav_ex
```
